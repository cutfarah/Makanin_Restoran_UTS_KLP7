# Makanin — UTS Frontend

## Deskripsi

Makanin adalah aplikasi web pemesanan restoran yang dirancang untuk memudahkan pelanggan dalam melihat menu, memilih makanan, melakukan pemesanan, dan memantau pesanan. Selain menyediakan fitur untuk pelanggan, Makanin juga memiliki halaman admin yang digunakan untuk mengelola menu dan pesanan restoran.

Aplikasi ini dikembangkan sebagai proyek UTS dengan fokus pada pengembangan frontend menggunakan Next.js dan React. Data aplikasi pada tahap frontend disimpan menggunakan LocalStorage sehingga fitur dapat dijalankan tanpa backend.

## Fitur Utama

### Customer
- Registrasi dan login customer
- Melihat daftar menu makanan dan minuman
- Melihat detail makanan
- Menambahkan dan menghapus makanan dari keranjang
- Melakukan checkout
- Memilih jenis pesanan dine-in atau online
- Memilih metode pembayaran sesuai jenis pesanan
- Melihat riwayat dan status pesanan
- Mengelola profil customer

### Admin
- Login admin
- Dashboard admin
- Melihat dan mengelola pesanan online
- Melihat dan mengelola pesanan dine-in
- Menambah, mengubah, dan menghapus menu
- Mengelola status pesanan
- Melihat data pesanan customer
